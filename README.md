# 🌸 Iris Flower Classification - ML Deployment using Flask

This project demonstrates how to train, serialize, and deploy a Machine Learning model using the classic **Iris dataset**. The web interface allows users to input flower measurements and get the predicted iris species.

## 🔍 Project Overview

- Built a classification model to identify Iris flower species: **Setosa, Versicolor, Virginica**
- Serialized the model using **Pickle**
- Deployed the model using a **Flask web application**
- Frontend created using basic **HTML/CSS**
